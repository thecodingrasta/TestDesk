# Support

Start with the [quickstart](docs/QUICKSTART.md), [installation](docs/INSTALL.md) and [troubleshooting](docs/TROUBLESHOOTING.md) guides. Search existing [issues](https://github.com/thecodingrasta/testdesk/issues) before opening a report.

For a defect, include the TestDesk version or commit, OS and architecture, runner/framework versions, minimal reproduction, expected result and actual result. Share only relevant, redacted configuration and bounded diagnostics. For compatibility reports, include whether discovery, exact selection, failures and cancellation work.

Use an issue for setup questions when the guides do not answer them. Support is community based with no guaranteed response time. Report vulnerabilities through [SECURITY.md](SECURITY.md).
