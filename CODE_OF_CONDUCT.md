# Code of conduct

Treat contributors and users with respect. Keep feedback constructive and focused on the work. Welcome questions and accept corrections without personal attacks.

Harassment, discrimination, threats, doxxing, sexualized attention and deliberate disruption are not accepted in project spaces.

Maintainers may edit or remove harmful content, restrict participation or ban accounts. They will consider the context and impact when deciding how to respond. Report public incidents with GitHub's reporting tools or contact a maintainer through a private contact listed on their GitHub profile. Do not post private details in an issue. If no private contact is listed, ask for one without describing sensitive details.

These expectations apply to issues, pull requests and other project spaces, including when someone represents the project elsewhere.
