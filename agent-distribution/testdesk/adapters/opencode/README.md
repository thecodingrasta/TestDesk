# TestDesk for OpenCode

Copy `.agents/skills/` into your repository or global skills directory and merge the `mcp.testdesk` entry from `opencode.json` into your project `opencode.json` / `opencode.jsonc` (or run `testdesk mcp-install --target opencode` / `opencode mcp add testdesk -- testdesk mcp`). Ensure `testdesk` is on `PATH` or specify its absolute executable path.
